# Python AttributeError

## Meaning
An object does not expose the requested attribute or method.

## Common Checks
- Inspect the object's type.
- Check attribute spelling.
- Check whether the object is None.
- Check library/API version.

## Verification
Use the original failing operation or a minimal reproduction to confirm that the diagnosis and proposed fix are correct.
